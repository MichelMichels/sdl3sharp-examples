# SDL3# examples

This repository contains ported examples from [the official SDL3 site](https://examples.libsdl.org/SDL3/) to [SDL3#](https://github.com/Sdl3Sharp/Sdl3Sharp).

## Why?

I like C# and wanted to broaden my horizons by learning a low level rendering library. Porting the examples seemed like a good way to learn how SDL works while also leveraging my existing .NET knowledge.

## State

Following examples are ported:

* 01 Clear
* 02 Primitives
* 03 Lines
* 04 Points
* 05 Rectangles
* 07 Streaming Textures
